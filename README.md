# Installation and run instructions for metatensor ecosystem on HPC clusters

This repository contains instructions about how to install and use software from the metatensor ecosystem (`metatensor`, `metatomic`, `metatrain`, …) on the following HPC systems:

- Alps cluster at CSCS (https://www.cscs.ch/computers/alps):
  - [Training with `metatrain`](CSCS-Alps/metatrain.md)
  - [Molecular dynamics with `metatomic` and i-PI](CSCS-Alps/molecular-dynamics-with-i-Pi.md)
  - [uenv recipes (LAMMPS + metatomic)](CSCS-Alps/uenv.md)
- [SCITAS clusters at EPFL (kuma GPU, jed CPU)](SCITAS-EPFL/README.md)

If you successfully used the code on other HPC systems, please share the corresponding instructions with us so we can add them here!
